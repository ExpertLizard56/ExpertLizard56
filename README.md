# ExpertLizard56

A self-hosted home setup: Android TV boxes, a small home server, and the apps that tie them together.

## Projects

| Project | What it is | Built with |
| --- | --- | --- |
| [Media Hub](https://github.com/ExpertLizard56/media-hub) | Server for the TV and Music apps: pairing, logs, antenna relay and music library. | Go, Docker |
| [Home Watch](https://github.com/ExpertLizard56/home-watch) | Health monitor for every machine at home: uptime, history and drive trouble. | Python, Docker |
| [StreamBox Keeper](https://github.com/ExpertLizard56/streambox-keeper) | Keeps a streaming box tidy while it sleeps and lets its remote control a Roku or Fire TV. | Java, Android TV |
| [App Updates](https://github.com/ExpertLizard56/app-updates) | Install files and update feed for the TV and Music apps. | Releases |

All projects run in Docker or as Home Assistant add-ons, unless they're Android apps.
